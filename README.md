# Система планирования ремонта

Консольное приложение для учета объектов ремонта, управления задачами и контроля статуса работ.

## Возможности
- создание карточек объектов и запуск ремонта;
- назначение задач конкретным исполнителям;
- переключение статусов задач (Не начато / В работе / Готово);
- поиск объектов по названию;
- фильтрация задач по статусу;
- обзор общего состояния ремонта;
- автоматическое сохранение данных в JSON-файлы.

## Структура проекта
- `main.py` – точка запуска и меню приложения;
- `repairs.py` – функции для работы с объектами и ремонтами;
- `tasks.py` – функции для управления задачами и исполнителями;
- `storage.py` – сохранение и загрузка данных (JSON);
- `utils.py` – вспомогательные функции безопасного ввода;
- `data/` – JSON-файлы с данными;
- `tests/` – автоматизированные тесты.

## Требования
- Python 3.x
- pytest
- flake8

Установка зависимостей: `pip install -r requirements.txt`
